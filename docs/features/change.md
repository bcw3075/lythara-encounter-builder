The Change button on the plan card: the GM edits the steps still to come (leave one out, its target, its square, its height), or sends Angel a note and the rest of the turn is planned again.

## Decisions
- **What Change does (Rhea, 2026-11-09):** asked whether it should offer a note to Angel, editing the steps herself, or both, she chose "Note and step edits": a note box that sends Angel back to re-plan with her words, and editing the plan herself (remove a step, change its target, pick a new square on the map), each edit checked by the same rules as Angel's plans. Rejected: a note only (step edits later); step edits only.
- **Names in her note become labels, and she sees exactly what Angel gets (Angel, from the module's standing rules: no PC's name reaches the thinker, and a monster acts only on what it perceives):** each name of a creature the monster perceives or knows as an ally becomes its label, its own name its own label. Send to Angel first shows "Angel will get: …"; Send this sends it. A name it doesn't perceive (a GM-hidden creature, a character off the map, a user) or one that fits several creatures (two Goblin Warriors) **blocks sending** with words saying why: swapping it for "someone it doesn't perceive" (the first build) would still tell the thinker the creature exists (review finding 9), and a first name alone went through as typed (review finding 1), so characters' longer name words (first names, surnames) are matched too.
- **A note doesn't use up a re-plan** (Angel's default): the GM asked, nothing went wrong, so `replan` runs with `counted: false`, as after a Seek.
- **The plan Angel makes from her note waits for Do it, even with Auto ticked** (Angel's default, from review finding 8): she changed the turn, so she sees the new plan before it runs. An accepted edit waits for Do it too.
- **What can be edited (Angel's default, within her answer):** the parts that are positions or creatures: `target` (and a Delay's `after`), `to`, `at`, `toward`, and a Fly's or Climb's `height`; and leaving a step out. Which Strike, spell or ability, or adding a step, is the thinker's: the note asks for that. An edited step's `why` becomes "changed by the GM" for the history.
- **When Change is offered:** a plan waiting on the card (ready, held, stopped) with steps left, and not when the next step was begun (a reload or a stop part-way: what it did isn't known). Not while running (Hold first), not while waiting for a plan, saves or the map's edge.
- **Taking out every step left ends the plan** with the turn left for the GM to end (as after a card she must apply: Auto doesn't end it).
- **A refused edit keeps the old plan;** the card says why in a warning line until the next run or change, and her draft opens again so she can fix it. Edits never go to the thinker and never count as tries.
- **A change is for the plan she saw:** the draft and the change carry the plan's fingerprint (`planPrint`: the step it stands at and the steps as written); a new plan from Angel, another GM's change or a step done meanwhile refuses it ("the plan changed…"). While a change is on its way Do it is hidden and the card offers Cancel it (for a runner that is offline or not answering).

## How it works
- Pure (`turn.mjs`): `changeProblem(r)` (why not now, or null; `CHANGEABLE` = ready, held, stopped; also "already on its way" while `go`, `ask` or `edit` is set), `editableParts(step)`, `applyEdits(raw, edits)` (per step `{ remove }` or changed parts; returns new raw steps, never touching the input; a changed step's `why` is "changed by the GM"), `noteForThinker(note, people)` (whole-word, case-insensitive, longest names first, trimmed to `NOTE_MAX` = 300; returns `{ text, unknown, ambiguous }`: perceived names become labels, the others are left as typed and listed), `planPrint(r)` (a short hash of the position and the written steps), `nameWords(name)` (words of 4 letters or more, brackets left out), and `describeChange`'s `gm` case: `The GM asks for the rest of this turn: "<text>"`.
- Any GM page (`fight.mjs`): `notePeople(combat, r)` lists every token on the scene (token and actor names, and for a character its name words) with its label when the monster perceives it or knows it as an ally (`r.labels`, the packet's `allies`) or its own label, then every other character in the world and every user with none. `previewNote` converts a note with it. `askAngel(combat, id, note, fp)` converts it again, refuses (`noteRefusal`) on any unknown or ambiguous name, a changed plan, an offline runner or `changeProblem`, and writes `ask` (the converted text, user, time, fingerprint). `changePlan(combat, id, steps, fp)` writes `edit` the same way. `cancelChange` clears a waiting `ask` or `edit`. All are on the module API's `fight` object (`askAngel`, `changePlan`).
- Runner: `act` takes an `ask` or `edit` on a changeable request before a `go`. `runChange` holds the same per-request guard as a run (`running`), so a change and a step never overlap and no Auto start runs mid-change; it checks `changeProblem`, the fingerprint, the fight's map and the token, then
  - a note (`sendNote`): converted once more against the scene as it is now (a token added since that matches a word refuses it); `replan` from the current step with `{ who: "gm", what: "note", text, user }`, not counted; the new request gets `gmWait`, which `judgeNow`'s Auto start and ticking Auto both respect, so it waits for Do it.
  - an edit (`useEdit`): `cleanPlan`, then `checkPlan` from the current step exactly as the look before each action does (`gather` with what the done steps spent and the last done step as `before`); a refusal's "Step N" is renumbered to the card's step; before saving, the request is read again (still changeable, same fingerprint). Accepted: `plan.steps` and `steps` become the done ones plus the new ones, `since` moves on, and `edits.<time>` keeps `{ user, pos, before, after }` (step words in labels). No steps left: the request is `done` with `gmEnded` and a note.
  - every refusal clears `ask`, `edit` and `go` (a Do it pressed meanwhile never runs the old plan), sets `changeVerdict`, and keeps `edits.<time>` as `{ user, pos, what, refused }` for the history. `runTurn` clears `changeVerdict` when the turn runs again.
- Card (`ui/turns.mjs`, owned by card-ui): Change beside Do it / Next step; the panel lists the steps still to come with Leave out, a target list (labels it perceives and its allies, shown by name with the label), square fields with **Pick**, height, a note box; Use my changes, Send to Angel (then the preview and Send this), Cancel. The draft lives on the window (`_draft`, keyed by request and fingerprint), survives redraws, is dropped when the plan changes or the window closes (the window object is reused when reopened), and reopens after a refusal. A redraw waits while the panel has the focus (`render` deferred, done on `focusout`). Pick: left click only; right-click, Escape, closing the window or a new map (`canvasTearDown`) end it with nothing left listening. One send at a time (`_sending`). Presses are noted for the history ("Send to Angel", "Use my changes") only after the change was handed in.
- History (`history.mjs`): an edit is a line at the step it changed from: "<user> changed the plan from step N: <new steps> (Was: <old steps>)", in names; a refused note or change "<user>'s change wasn't used: <why>"; a note shows as the re-plan's "Asked again" line.
- Prompt version 21 tells the thinker what a GM note is and that it comes before the monster's own tactics.

## Traps
- **A note's names must be caught on the GM's page, shown, and checked again on the runner** (review findings 1, 2, 9): only full token names were swapped at first, so a first name went through as typed, two same-named tokens took the first one's label, and "someone it doesn't perceive" told the thinker a hidden creature existed.
- **A change and a run must share one guard** (review findings 4, 5): with separate guards a Do it or an Auto start could run the old steps while an edit was being saved, and `runTurn`'s route update then wrote the old list back, so `plan.steps` and `steps` no longer matched.
- **The plan's steps and the checked steps are two lists of the same length:** the request's `plan.steps` holds them as the thinker wrote them (what an edit changes and `checkPlan` reads), `r.steps` the checked ones (what runs and what the card describes). An edit must replace both from the current step on, as `lookAgain` reads them.

## Open items
- A note while the turn waits for a plan (state requested), or after Angel gave up: not offered yet (the turn has no plan to re-plan from); she can Play it myself.
- A burst's "From corner" picked on the map is the clicked square's top-left corner, not the nearest corner to the click (review nit 16): easy to land one square off; type it if it matters.
- Adding a step, or changing which Strike or spell: through a note only.
