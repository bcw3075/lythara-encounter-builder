Built: a buff spell's linked spell effect is put on by the module (itself, one friend, or itself and the friends its area catches; an aura effect such as Bless's only on its caster), with the cast rank as its level; an action that gives its effect to "you and all adjacent allies" (Channeled Protection) puts it on each. - P-2, u-177 (2026-11-25, 1:09 PM Eastern): Harm and Heal at every action count, "She should be able to do those actions yes, but that needs to be a real thought call because thats giving up a spellslot that can't heal now so thats a big chooise to make". Feature docs: spells.md, packet.md.
- u-175 (2026-11-25, Rhea): Auto PCs' reactions keep waiting for the GM's OK, no change (recorded in 0.46.1's follow-up commit; nothing built here).

## Review
<!-- The independent reviewer's findings, each marked verified true or false and what was done.
     Required when code changed; otherwise write `waived by Rhea <date>` with her reason. -->
- R1 verified true (Lay on Hands): its base item has no save and no damage, so the step had no save and `vitalOf` returned null at its first line. Fixed: `vitalOf` no longer needs damage on the base item, each variant carries its own save, and `checkSpell` takes the save and `damaging` from the variant (unit vt-9). Heal's and Harm's base items do have a basic Fortitude save (read live), so they were right.
- R2 verified false: Lay on Hands links one effect, whose own rules turn its +2 AC into -2 on an undead (`AdjustModifier` predicated `self:mode:undead`, read live). No change.
- R3 verified true (rules): the 3-action Heal and Harm "target all living and undead creatures" with no willing clause. Fixed: the emanation heals every creature of its kind in it, foes too; `checkSpell` refuses a foe it would heal unless `deliberate`; packet, prompt and card words say so (unit vt-7).
- R4 verified true: a hidden target had no `undead`/`notLiving` though the packet named its `being`. Fixed: targets carry it whatever the state.
- R5 verified true: no dead check on a foe. Fixed: targets carry `dead`, and Heal or Harm at a destroyed foe is refused (unit vt-8).
- R6 verified false: `record` goes through `combat.update` on a flag path, which merges nested objects; `applied` has always been written the same way.
- R7 verified false: `noRows` is set only in `awaitAreaSaves`, which isn't reached when nobody has a row.
- R8 verified true: a variant loaded without `castRank` reads rank 1 (read live). Fixed: every `loadVariant` with an overlay passes `castRank: step.rank`. Whether the cast keeps the variant is a live check (vt-1).
- R9 verified true: an area buff put its effect on a GM-hidden ally. Fixed for area buffs and for the group ability (`alliesOf` was unfiltered there too).
- R10 verified true in part: the action cost comes from the ability's own actions (as for `self`), but nothing refused it when its effect was already on. Fixed: `groupOn`, refused like a stance already on.
- R11 verified true (comment only): the healing roll already holds the caster's healing bonuses; the comment said "healing received". Comment fixed.
- R12 verified true: the area result said "healed its friends" with automatic damage off. Fixed.
- R13 verified true (low): the group regex had no save exclusion. Fixed.
- R14 verified false: the packet's `note` is the replan reason passed to `buildPacket`, not the GM's request note; GM notes never reach the thinker.
- R15 verified false: no `healAt`, `heals` or `healVariants` left (grep).
