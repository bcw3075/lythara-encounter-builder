- An independent reviewer (Sonnet, a 6 KB diff, one file read) found, each checked by Angel:
  - (item 8) a blinded reactor who still perceives the caster would lose the offer for a silent spell: **true as read, but it is Rhea's ruling** (blinded and no spoken part: not offered), and the test in 0.39.12 showed Visioner's state does not change for a blinded reactor; kept as built.

  - (items 5, 6) `spoken` is the concentrate trait only, read from the spell item's traits: a modelling limit, named in the feature doc; not a bug.
  - (item 2) no regression: gates without `o.cast` leave a blinded reactor as before.
