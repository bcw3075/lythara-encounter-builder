<!-- The independent reviewer's findings, each marked verified true or false and what was done.
     Required when code changed; otherwise write `waived by Rhea <date>` with her reason. -->
An independent reviewer (Opus) read one reading file (45 KB: the diff of `scripts/`, two helper functions, the feature doc, the record's decisions; about 102,000 tokens used against a 40,000 ceiling, noted again). 15 findings, each checked against the code:
1. A prone monster was shown Stride squares: **true**. Fixed: `canMove` is false while prone (it must Stand first); it is still told who flanks it. The prompt says so.
2. `discipline` might not exist where `flankFor` is called: **false** (`buildPacket` declares it for the band, above the call).
3. The route's shape (sync, start square included, the Step's signature): **false** (`mover`'s route is synchronous, `findRoute` and `findStep` both return the start square first, and `{ step: true }` is the Step's own call).
4. A hidden or pointed-out foe was described from its real sheet (reach, conditions, weapon): **true**. Fixed: a foe it doesn't see counts with a 5-foot reach, as able, and is never guessed at.
5. A reach of 0 became 5: **true**. Fixed for both the monster's Strikes and a creature's reach. Tiny half squares: false (`sizeOf` is at least 1).
6. `backAt` might count the square it leaves as occupied: **false** (`mover` leaves the mover itself out of its occupancy map).
7. Labels changing between turns, and other reactions writing a `reactive` line: **false** (labels last the whole fight; only Reactive Strike and Attack of Opportunity write that line).
8. Field names read from `you`: **false** (`square` is the top-left, `actionsLeft` is always set, a melee Strike has no `range` key).
9. Route searches not cached: **true**. Fixed: one answer a square a packet, and nothing further than two Speeds is tried.
10. A paralyzed, petrified or restrained ally counted as a flanker: **true**. Fixed (the same test as for a foe).
11. New card text said "it": **true** for the card's line; reworded. The prompt's own "it" for "this monster" is the prompt's standing style and is left.
12. `tookFlank` counted any step through a listed square: **true**. Fixed: the plan's last move. A plan ending on a flank square beyond the four listed still gets the line (rare; left, the thinker's reason then says so).
13. A creature that only guards is never told it is flanking: by design (it doesn't think in flanks); the prompt now says the field goes only to seekers. Its card line on every turn with an open flank is what F-10 asks for.
14. `heightUp` might not return 0: **false** (it returns a number, 0 on the ground).
15. Every creature with no Mind counts as Cunning: **false** in effect (every monster has at least its stat block's Mind; only a party member Angel plays can have none).
