## Review
<!-- The independent reviewer's findings, each marked verified true or false and what was done.
     Required when code changed; otherwise write `waived by Rhea <date>` with her reason. -->
- Independent reviewer (a separate agent that hadn't seen the work) read the diff, the feature docs and the code around it; 7 findings, each checked in the code:
  1. verified true: `crossesWalls` counted a line only touching a wall on one side, by the wall's drawing direction, and a Large creature's centre sits on grid lines, so a Large glider could straddle or pass a wall drawn in two pieces. Fixed: centres nudged off the grid lines and a big creature's end footprint checked for a wall through its inside; two unit tests (the wall drawn each way and in two pieces).
  2. verified true: after an ability whose effects the GM applies, the request waits as `ready` like a Next-step wait, so ticking Auto would run past it. Fixed: `gmWait` on that pause, cleared when the turn runs again; the Auto handler skips it.
  3. verified true: Auto ticked during the game's pause could later restart a turn that had gone `stopped` meanwhile (and `judgeNow`'s own Auto start had the same gap). Fixed: the request is read again after the pause and runs only if still ready at the same step, not held, not waiting on the GM, Auto still ticked.
  4. verified true: a glider's refusals said "only through soil" and the ground key named rock. Fixed: its own words for deep water and for what it can't glide through, "earth or rock" in checkPlan, and no rock letters or key for a glider.
  5. verified true (a missing hint, not a wrong result): the ground map doesn't tell a stone wall's "#" from a wooden or door one for a glider. Left as an open item in `docs/features/moves.md`; the refusals name what stops it.
  6. verified true: a long wall was judged at its middle only. Fixed: five points along it, stone when at least three are in a stone-walls region.
  7. verified true, low impact: one-way walls that aren't stone stop a glider both ways (the safe side). Open item in `docs/features/moves.md`.
- Found in the live test before the review's fixes went in (2026-11-09): on the hand-built dungeon the solid rock outside the rooms has no walls through it, so a glider could have come up inside it. Fixed: `openFloor` (where creatures on the surface could walk to) for a glider's `surfaceAt`.
