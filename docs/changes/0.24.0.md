- [general] PF2e runs a creature's turn start and turn end once a round (the combatant's `roundOfLastTurn` and `roundOfLastTurnEnd` flags): a creature that gets a second turn in the same round (a Delay, by a module or by PF2e HUD's hourglass) fires neither `pf2e.startTurn` nor `pf2e.endTurn` again, and persistent damage isn't applied twice. The opposite had been assumed since 0.12.0 and put on the GM's card → filed: foundry-mod-tools docs/foundry-traps.md (section 8; moved there from the skill card in the 2026-11-10 efficiency review, found there again at this start)
- [general] `game.time.serverTime` restarts at every world launch, so a time stored on it can come true again in a later launch ("ahead of now" only catches it until the new clock gets there). Keep the launch beside the time: `game.world.lastPlayed` is the same text on every page of one launch → filed: foundry-mod-tools docs/foundry-traps.md (section 8; moved there from the skill card in the 2026-11-10 efficiency review, found there again at this start)
- [general] Start-of-turn work measured on 14.370, PF2e 8.7.0, Workbench 7.7.5 with every GM page on the server PC: the last change to a creature reached the runner 100 to 270 ms after the turn change, gaps under 70 ms, whichever GM page was active; a module that reads a creature at its turn start should wait for those changes to go quiet, not a flat time → filed: foundry-mod-tools docs/foundry-traps.md (section 8; moved there from the skill card in the 2026-11-10 efficiency review, found there again at this start)
