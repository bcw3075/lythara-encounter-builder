## Review
<!-- The independent reviewer's findings, each marked verified true or false and what was done.
     Required when code changed; otherwise write `waived by Rhea <date>` with her reason. -->
- Independent reviewer (Opus, a reading file of the diff at -U1, the decisions and the feature doc changes; about 124,000 tokens against a 60,000 ceiling). Each finding checked against the code:
- 1 (card notes with PC names and damage reach the thinker) verified false: the packet's `note` is only "Asked again mid-turn: ..." built from `describeChanges` (labels); request notes go to the GM's card, not the packet (`buildPacket`'s `turn.note`, set only in `replan`).
- 2 (an Ask Angel answer that echoes the level pins it) verified true as a risk: fixed, a level the same as the sheets' doesn't set `partyLevelSet`.
- 3 (Elemental Blast's action-cost flag written as 1 where none was) verified true, no change: an unset flag means 1 to PF2e, so the sheet behaves the same; the flag is needed because `ElementalBlast#attack` reads the cost from it (checked live while building).
- 4 (a caster who is down or never gets another turn keeps its sustained spell) verified true: fixed, each turn change ends a spell whose caster is down or dead, or that went a whole round without a Sustain.
- 5 (a fresh cast of a sustained spell orphans the old area) verified true: fixed, the old one's areas go first.
- 6 (Heal at a dead or non-living ally) verified true: fixed, a dead ally or a construct that isn't living goes to the card.
- 7 (the ally-effect test is too broad; "another kobold" could go on itself) verified true: fixed, "creature" and "kobold" no longer count, and an ability whose text says "another" refuses its own user.
- 8 (a new stance doesn't end the old one) verified true: fixed, an effect named "Stance: ..." removes the creature's other stance effects first.
- 9 (Sustain with an aim on a non-repeating area drops the aim) verified true, no change: the prompt asks for an aim only on a repeating area, and the Sustain still happens; the card says "Sustains X".
- 10 (a stub record after an async gap) verified possible only if the GM ends the turn during a Sustain step's save; no change, low.
- 11 (what's left reads the sheet at render; "PT1M" words) verified true: the reading at render is meant (the sheet is the truth); the frequency words fixed.
- 12 (no actions gives no missiles) verified: such a step already falls back to the card, and checkSpell asks for the actions of a "1 to 3" spell; no change.
- To check, taken into the live test: `-=` deletion through `saveTurns` (used the same way elsewhere in this file since 0.9), Force Barrage at rank 3, a blast beyond 30 feet, Heal's ally target lookup, the stance effect's name.
- Found in the live test round, fixed in the same test build: (a) Elemental Blast's 2-action roll went out as 1 action: PF2e's `actionCost` flag is rewritten from the item's RollOption rule at each prepare, so writing the flag did nothing; now set with `actor.toggleRollOption("elemental-blast", "action-cost", item, true, "2")` and put back after. (b) Channeler's Stance's effect is named "Effect: ...", not "Stance: ...": a new stance now ends the effects of the creature's other stance actions (by their self-effect sources). (c) Counterspell treated a monster's Magic Missile and a wizard's Force Barrage as different spells: the legacy and remastered slugs now match, and a reactor who knows the spell but has no unspent copy is told so. (d) "1 missile, which always hit" now reads "hits".
