## Decisions made
<!-- Rhea's answers, each with the question it answered and the date. -->
- No question went to Rhea in this release. Angel's choices, hers to change:
  - Settle time is a wait for quiet, not a longer flat wait: 300 ms with no change to any creature in the fight, at least 400 ms after the turn change (what it was), at most 3 s. A flat wait long enough for a slow connection would slow every turn; this adds about 0.1 to 0.2 s to a turn on the server PC and stretches only when changes are still arriving.
  - The Delay card's note about undoing start-of-turn effects is gone: the live test showed PF2e doesn't apply them a second time.
  - The listening time is tied to the world launch through a new hidden setting, rather than cleared when the runner's page loads (a reload of the runner mid-fight would have turned a real listener's light off).

An independent agent read the diff against 12f59bc, the record and the feature docs (first test build's code, before any install). Each finding was checked against the code.
1. A stamp left by an earlier turn change made a later tick skip the wait (`settle` read a 20 s old `turnAt` and returned at once, `settled` about 20000). 2. Slow work before `settle` (a fall with its rolls) could use up the cap, so the wait ended at once. Verified true (rare). Fixed by the same `settleFrom`: under 700 ms of cap left counts from now.
3. The quiet rule can't help when the first change arrives after the 400 ms minimum (a far-off active GM). Verified true by reading `settleWait`. Fixed: `settle` first waits for PF2e's own turn start to reach the page (the combatant's `roundOfLastTurn` naming this round), then for quiet; unit test; the dependence on PF2e writing that flag is a Trap in turn-loop.md.
4. Docs against code: the unverified list named the setting `brainBoot` (it is `brainLaunch`); turn-loop.md still said "a short wait"; the mid-turn tick wording. Verified true, all three fixed.

7. `launchNow` falls back to empty text if `lastPlayed` were missing, which brings back the clock-only test. True by design; written into brain.md. Whether `lastPlayed` changes at every launch is checked live (br-3).

The opposite had been assumed since 0.12.0 and put on the GM's card → card proposed: foundry-module-dev
