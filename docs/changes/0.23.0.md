## Decisions made
<!-- Rhea's answers, each with the question it answered and the date. -->
- No question went to Rhea in this release. Angel's choices, hers to change:
  - Settle time is a wait for quiet, not a longer flat wait: 300 ms with no change to any creature in the fight, at least 400 ms after the turn change (what it was), at most 3 s. A flat wait long enough for a slow connection would slow every turn; this adds about 0.1 to 0.2 s to a turn on the server PC and stretches only when changes are still arriving.
  - The Delay card's note about undoing start-of-turn effects is gone: the live test showed PF2e doesn't apply them a second time.
  - The listening time is tied to the world launch through a new hidden setting, rather than cleared when the runner's page loads (a reload of the runner mid-fight would have turned a real listener's light off).
