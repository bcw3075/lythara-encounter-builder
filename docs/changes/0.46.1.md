- 4 verified true (risk): a ChoiceSet's predicates were tested against the bearer only, wrong for an effect put on a friend. Fixed: auto-pick only for `mode: "self"`, never when a choice's predicate names `origin:`, `parent:` or `item:`, and a predicate that throws leaves it to the GM.
- 5 verified true: `wallsIn` gave whole wall endpoints, beyond the ground's window. Fixed: each wall is cut to the window (unit test added). Dropping walls between two blocked squares: not done, they cost little.

- 8 verified true: `forFriends` matched "non-allies" and "enemy or ally". Fixed: target text naming "non", "not" or "enem" doesn't count. Heal's area stays refused (it damages undead): as designed.
- 9 verified true (nit): no unit tests for Pack Attack, the ChoiceSet pick, the toggles, `forFriends`, `critText` or the spinner; they all need PF2e documents and are in the live retest (sd-pack, sp-fix461, ab-5, ab-6).
