## Review
<!-- The independent reviewer's findings, each marked verified true or false and what was done.
     Required when code changed; otherwise write `waived by Rhea <date>` with her reason. -->
An independent agent read the diff at -U10, this record, the touched feature docs and the functions the diff calls into (one reading file, about 40 KB). Each finding checked against the code:
1. **True: the card stripped squares from refusals, her Change's problems and notes.** `named` on the card wrapped everything in `plainSquares`, refusals and `changeVerdict` included, and she fixes a Change in squares. Fixed: a second namer, `said`, without it, for the verdict, the change's verdict and the notes (the card and the left-over note).
2. **False: the nudge's `refused.0` and retry event collide with reject's.** Reject writes `refused.<tries>` from 1 up, so `0` is the nudge's own; events are keyed by a fresh `seq` from `eventChange`, never by (kind, request, tries), so a second retry event with the same `tries` is still a new event.
3. **True: a GM's own note could be pushed back.** A replan from her note (`why` with `who: "gm"`) could be told to use every action against what she asked. Fixed: no nudge when the request's `why` holds a GM entry. Her direct Change goes through `useEdit` and `checkPlan`, not `judgeNow`, so it was never nudged (checked).
4. **True in part: `plainSquares` ate real numbers.** "by 4, 12 damage", "in 1, 2" and "1,200" matched. Fixed: the word before a square is one of place only (to, at, toward(s), into, onto, from, near), and a bare `18,17` takes at most two digits after the comma; a unit test holds the three.
5. **True: a closed secret door counted as walkable for the approach.** Fixed: only an ordinary door (`WALL_DOOR_TYPES.DOOR`) that is closed stops no walking; a secret door stays a wall.
6. Minor: **true**, the card said "Nothing to do this turn" on a re-plan: it says "Nothing more to do this turn" when the request has a `parent`. **True but left**, the nudge's words show on her card while the retry is out: they read plainly to her too and go when the new plan lands. **True, no harm**, the nudge comes before judgeNow's untick and Play it myself checks: at most one thinker call wasted, and `nudge` itself stands down for a `manual` request.
To check, each checked: `writeBrief`'s callers are only Monster Minds and band writes (bandlib, library); a brief from a chat (`submitBrief`, builder.mjs) uses `setFlag` and still loads into an open window. A reaction request ending the turn on an idle plan: `endsItself` now counts an idle plan only for a request that isn't a reaction. The runner's 10 s left-over check needs `autoEnd`, which `endAfter` writes for an idle plan too, so a lost 2 s timer is still caught. A late duplicate of a nudged plan is judged again and passes with the note (the nudge is once a request): no harm. Left as open items, not changed by this release: takeMinds matching rows by index and uuid (older than 0.39.11; it now runs before a build too), and whether fight-time routing goes through a closed door the build counted as walkable (the build only places; fight-time moves use the scene's walls, so a monster behind a closed door takes the long way or opens it as before).
