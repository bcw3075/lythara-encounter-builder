5. verified true: a taken brief lived only in the window. Fixed: `markApplied` keeps it on the scene's `brief`.
6. verified true: an answer during Preview changed the brief under it. Fixed: not taken while a Preview runs; taken when it ends.
7. verified true (bridge): a throw in a note left the ask unanswered. Fixed: the notes' errors are caught and the loop is wrapped so the box always hears back.
8. verified true (bridge): a stopped worker said nothing. Fixed: it answers a new ask at once with why (bridge check added).
