## Review
<!-- The independent reviewer's findings, each marked verified true or false and what was done.
     Required when code changed; otherwise write `waived by Rhea <date>` with her reason. -->
Independent reviewer (a general-purpose agent that hadn't seen the work), 2026-11-09, on the diff and this record. Each finding read in the code (and the note conversion run) before acting:
1. A first name, a character not on the map or a user name in a note went to the thinker as typed: **verified true** (ran it: a first name came out unchanged). Fixed: characters' name words, every character in the world and every user are matched; a name the monster doesn't perceive blocks sending; the note is previewed on the GM's page and checked again on the runner.
2. Same-named tokens all took the first one's label: **verified true** (ran it). Fixed: a name that fits several creatures blocks sending, asking for the label.
3. A draft or a waiting edit could land on a newer plan under the same request: **verified true** (`submitPlan` accepts a new plan while ready at step 1; a stall event can bring one). Fixed: the plan's fingerprint (`planPrint`) on the draft and the change, checked on both sides.
4. Do it stayed clickable while a change waited, and a refused change then ran the old plan: **verified true**. Fixed: Do it hidden while `ask` or `edit` is set; every refusal clears `go`.
5. A run could start while an edit was being saved, breaking the alignment of `plan.steps` and `steps`: **verified true by reading** (the guards were separate and nothing re-read the state). Fixed: one guard (`running`) for both, and the request read again before an edit is saved.
6. Pick took any button, had no Escape, and could leave a listener behind: **verified true**. Fixed: left click only, right-click and Escape cancel, ends on close and on `canvasTearDown`, no maximise on a closed window.
7. Ticking Leave out threw in the Angel/Auto checkbox handler: **verified true**. Fixed: that handler is limited to the creature rows.
8. A note on a held turn with Auto ticked ran the new plan by itself: **verified true**. Decided (Angel's default, in the feature doc): the plan Angel makes from her note waits for Do it (`gmWait`).
9. "Someone it doesn't perceive" told the thinker a hidden creature exists: **verified true**. Fixed with 1: such names block sending.
10. A change written while the runner is offline stuck with no cancel: **verified true**. Fixed: `askAngel` and `changePlan` refuse when the runner is offline, and the card offers Cancel it while a change waits.
11. A redraw while typing took the field away; a number not yet committed was lost: **verified true** (redraws on every flag update). Fixed: fields save on `input`, and a redraw waits while the panel has the focus.
12. A double send: **verified true**. Fixed: one send at a time (`_sending`).
13. A refused change lost the draft: **verified true**. Fixed: the draft stays until accepted and reopens after a refusal.
14. Refusals numbered from the edited list: **verified true**. Fixed: renumbered to the card's step.
15. A half-filled square became "unchanged": **verified true** (worse: `Number("")` is 0). Fixed: refused with "a square needs both numbers".
16. A burst's corner from Pick is the clicked square's top-left: true, by design; noted in the feature doc's Open items.
17. An accepted edit didn't move `since`: **verified true**. Fixed.
18. A press noted before the send could fail: **verified true**. Fixed: noted after the change is handed in.
19. The new section split `notePress`'s doc comment from it: **verified true**. Fixed.
Found in the first live round (test build 1) and fixed in test build 2, read again line by line rather than re-reviewed (four small changes): Angel's plan reason on the card showed labels (now in names, as the history already did); closing Monster Turns kept the Change draft, which reopened with the window (now cleared on close); the prompt still spoke of "someone it doesn't perceive", which can no longer be sent (reworded); a refused change left no reason in the history (now a line with the reason).
